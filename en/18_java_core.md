### Java platform

**Definition:** Java is a statically typed, object-oriented language that compiles to bytecode for the JVM, so the same artifacts can run on many operating systems with a compatible runtime.

**Key idea:** Learn the language model (types, classes, packages) and the JDK tools (`javac`, `java`, build tools) before frameworks — Spring and the ecosystem sit on this foundation.
